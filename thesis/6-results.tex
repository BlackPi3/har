\section{Experiment Results}

This chapter presents the experimental results of all training scenarios on both primary datasets (UTD-MHAD\cite{chen2015utd} and MM-Fit\cite{stromback2020mm}) using the evaluation protocol described in \Cref{chap:experimental-setup}. \Cref{tab:main-results} presents the test-set performance for all scenarios, representing the best configurations found during the 3-pass HPO introduced in \Cref{chap:implementation}.

\paragraph{Loss Ablations.}
Scenario 2.2 ($\gamma=0$) exhibits catastrophic failure, with F1 dropping over 90\% on both datasets. This demonstrates that the regression loss is essential. Classification gradients alone cannot guide meaningful pose-to-accelerometer simulation. Scenario 2.3 ($\beta=0$) shows performance degradation on both datasets, though more pronounced on MM-Fit ($-$4.9\%) than UTD-MHAD ($-$0.9\%), suggesting the feature similarity loss provides regularization benefits but not as pronounced as regression loss.

\paragraph{Architecture and Training Variants.}
Unlike the loss ablations, the remaining scenarios do not exhibit consistent trends across datasets. On UTD-MHAD, signal-level adversarial training\cite{arjovsky2017wasserstein,gulrajani2017improved} (Scenario 4.2, +3.3\%) and auxiliary NTU data\cite{shahroudy2016ntu} (Scenario 3, +2.1\%) appear to improve generalization, with Scenario 4.2 achieving the best overall F1 of 0.689. The architectural variants (Scenarios 2.4 and 2.5) also show modest gains (+0.7\% to +1.3\%). However, these improvements do not transfer to MM-Fit, where the baseline achieves the highest F1 (0.857) and all variants show degradation ranging from $-$1.5\% to $-$7.7\%. One pattern that does hold across both datasets is the underperformance of feature-level adversarial training\cite{ganin2016domain} (Scenario 4.1), which degrades F1 by 6.0\% on UTD-MHAD and 5.3\% on MM-Fit. This may indicate that adversarial alignment at the feature level conflicts with the explicit similarity loss or discards task-relevant information. The overall divergence between datasets could suggest that the proposed variants tend to benefit smaller datasets with limited training data, while larger datasets may already provide sufficient coverage for the baseline to perform well.

\paragraph{Scenario 2.2: Regression Loss ($\gamma$).}
\Cref{fig:scenario22-waveforms} visualizes the regressor outputs with and without MSE supervision. With MSE loss enabled (left column), the simulated signals track the real accelerometer waveforms reasonably well, capturing the general shape and timing of activity-related peaks. Without MSE loss (right column), the regressor produces chaotic, high-frequency noise that bears no resemblance to the real signals. The output magnitudes are often orders of magnitude larger than the real data. Baseline achieves MSE $\approx 0.2$--$0.3$, while the no-MSE variant produces MSE values ranging from $10^2$ to $10^6$.

These out-of-range simulated signals appear to actively harm classification rather than simply failing to help. When the feature extractor receives such inputs during training, it may learn representations that accommodate the noise rather than focusing on activity-discriminative patterns. This could explain the catastrophic F1 drops of over 90\% on both datasets. The simulated path does not just provide zero benefit, but potentially corrupts the shared feature extractor's learned representations. Without direct signal-level supervision, the regressor receives gradients only through classification loss backpropagated through the feature extractor, which appears insufficient to guide meaningful pose-to-accelerometer mappings.

\paragraph{Scenario 2.3: Feature Similarity Loss ($\beta$).}
The feature similarity loss enforces alignment between real and simulated feature embeddings. Analysis of optimal $\beta$ values across scenarios reveals dataset-dependent patterns: UTD-MHAD configurations tend toward higher values (10--100), while MM-Fit configurations consistently select lower values (1--2). This pattern may indicate that the similarity loss compensates for limited training data by providing stronger regularization toward domain-invariant representations. Smaller datasets appear to benefit more from explicit alignment constraints.

\paragraph{Scenario 2.4: Separate Classifiers.}
Scenario 2.4 uses separate classifiers for real and simulated paths while sharing the feature extractor. \Cref{fig:scenario23-f1} shows the validation F1 for each classifier over training. On both datasets, the simulated classifier $C_{\text{sim}}$ achieves comparable F1 to the real classifier $C$, despite never seeing real accelerometer data during training. This suggests the shared feature extractor produces reasonably domain-invariant representations. The simulated path tends to converge faster, possibly benefiting from more consistent training signal without sensor noise variability. The same pattern is visible for MM-Fit where the simulated path finds the highest F1 sooner than real path.

\paragraph{Scenario 2.5: Separate Feature Extractors.}
Scenario 2.5 uses separate feature extractors for real and simulated paths while sharing the classifier. The effect appears dataset-dependent: UTD-MHAD shows a modest improvement (+1.3\%), possibly because separate extractors allow the simulated path to specialize without constraining the real-data extractor. MM-Fit shows degradation ($-$4.2\%), which may indicate that the larger dataset benefits more from implicit alignment through shared weights. \Cref{fig:scenario24-confidence} examines whether the shared classifier receives compatible features from both extractors by tracking classifier confidence (mean softmax probability of predicted class) over validation. On both datasets, confidence levels on real and simulated features converge to similar values, suggesting the feature similarity loss ($\beta$) encourages compatible representations. However, the classifier remains consistently more confident on real features, indicating some residual domain gap that separate extractors may not fully bridge.

\paragraph{Scenario 3: Auxiliary Pose Data Analysis}
Scenario 3 incorporates NTU RGB+D\cite{shahroudy2016ntu} as a secondary pose-only dataset to provide additional training signal for the regressor. The hypothesis is that additional pose diversity may help the regressor learn more generalizable pose-to-accelerometer mappings. However, the aggregate results show divergent effects: UTD-MHAD improves (+2.1\%) while MM-Fit degrades ($-$7.7\%).

\paragraph{Per-Class Analysis.}
\Cref{fig:scenario3-perclass} shows per-class F1 scores for baseline versus auxiliary training. On UTD-MHAD, some activities improve (Draw Triangle +13\%, Draw Circle +6\%, Swipe Right +8\%) while others degrade (Wave $-$11\%, Swipe Left $-$10\%, Tennis Serve $-$14\%). Notably, the changes do not simply correlate with having direct NTU equivalents, Wave has a semantic match (Hand waving) yet degrades, while the drawing gestures have no direct equivalent yet improve. Among activities with NTU equivalents, results are mixed: Throw (+4\%) and Boxing (+3\%) improve, while Wave ($-$11\%) and Push ($-$8\%) degrade. This suggests the auxiliary data may provide general motion diversity rather than activity-specific transfer. On MM-Fit, lower-body exercises show improvement (Squats +21\%, Lunges +5\%) despite no direct NTU equivalents, possibly benefiting from NTU's walking and sitting motions. Jumping Jacks, the only MM-Fit activity with an NTU equivalent, shows minimal change (+1\%). Fitness-specific arm exercises degrade (Bicep Curls $-$5\%, Situps $-$3\%, Tricep Extensions $-$2\%), which lack NTU equivalents.

\paragraph{Domain Compatibility.}
The divergent effects may be explained by domain compatibility between the primary and auxiliary datasets. Tables~\ref{tab:utd-ntu-overlap} and~\ref{tab:mmfit-ntu-overlap} show the activity class overlap between each primary dataset and NTU RGB+D. NTU's 60 action classes have approximately 33\% overlap with UTD activities (\Cref{tab:utd-ntu-overlap}). In contrast, MM-Fit's fitness exercises have only about 9\% overlap with NTU's daily activities (\Cref{tab:mmfit-ntu-overlap}). Both datasets select the same auxiliary loss weight ($\lambda_{\text{aux}} = 0.25$), yet the net effect differs substantially, suggesting that activity class compatibility may matter more than weight tuning when auxiliary data has poor domain match.

\section{Adversarial Training Analysis}
\label{sec:adversarial-analysis}

Adversarial training aims to reduce the domain gap between real and simulated data by training a discriminator to distinguish between them, while simultaneously training the generator (feature extractor or regressor) to fool the discriminator. We evaluate two approaches: feature-level discrimination (Scenario 4.1) and signal-level discrimination (Scenario 4.2). Signal-level discrimination improves UTD-MHAD (+3.3\%) but degrades MM-Fit ($-$6.8\%), while feature-level discrimination consistently underperforms on both datasets ($-$6.0\% and $-$5.3\% respectively).

\paragraph{Scenario 4.1: Feature-Level Discriminator.}
The feature-level discriminator operates on learned representations $\mathbf{z}_{\text{real}}$ vs. $\mathbf{z}_{\text{sim}}$, using GRL\cite{ganin2016domain} with binary cross-entropy loss. \Cref{fig:scenario4-dynamics} shows important metrics on validation set. On both datasets, discriminator accuracy fluctuates around 50\%, indicating the feature extractor learns to produce representations that the discriminator cannot distinguish. The GRL $\lambda$ parameter follows a sigmoid schedule from 0 to 1, gradually introducing adversarial gradients. Despite successfully fooling the discriminator, classification performance does not exceed baseline and in fact degrades on both datasets. The baseline's explicit feature similarity loss ($\beta$) may achieve a better trade-off by encouraging alignment without eliminating domain-specific signals.

\paragraph{Scenario 4.2: Signal-Level Discriminator.}
The signal-level discriminator operates on raw accelerometer signals $\mathbf{a}$ vs. $\tilde{\mathbf{a}}$, using WGAN-GP\cite{arjovsky2017wasserstein,gulrajani2017improved} with alternating updates. This scenario uses staged training: an initial pretraining phase establishes reasonable signal structure before introducing adversarial feedback. \Cref{fig:scenario42-dynamics} shows the similar metrics to scenario 4.1, with the vertical dashed line marking the transition from pretraining to adversarial training. During pretraining, MSE loss drops rapidly, establishing basic signal structure. Once adversarial training starts, discriminator accuracy initially spikes then gradually decreases toward 50\% as the regressor improves. The regressor maintains signal quality (low MSE) while simultaneously learning to fool the discriminator. On UTD-MHAD, F1 continues improving after adversarial activation, yielding a +3.3\% improvement over baseline. However, MM-Fit shows degradation ($-$6.8\%), possible because the regressor is already simulating good enough signals. It can be seen that MSE loss very quickly reduces and does not seem to be affected by discriminator.

\paragraph{Comparison.}
Both approaches successfully train the discriminator to near-chance accuracy, confirming that domain alignment is achieved at their respective operating points. However, domain alignment at the feature level does not translate to improved classification, while signal-level alignment provides gains on the smaller dataset. This may suggest that fooling the discriminator is necessary but not sufficient for improving downstream task performance.

\paragraph{Hyperparameter Optimization Insights.}
\Cref{tab:optimal-configs} summarizes the best loss weight configurations found for each scenario. During HPO, both datasets consistently gravitated toward smaller batch sizes and window strides, so we fixed data parameters (UTD-MHAD: batch 16, stride 0.1s; MM-Fit: batch 64, stride 0.2s) to maintain practical training times. UTD-MHAD configurations show higher $\beta$ values (5--100) compared to MM-Fit (1--10), suggesting that the smaller dataset benefits more from explicit feature similarity enforcement. The architectural variants on UTD-MHAD (Scenarios 2.4 and 2.5) select particularly high $\beta$ values (50--100), possibly compensating for the loss of implicit alignment that shared weights provide.
